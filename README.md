## 🚀 Selected Projects

### 👁️ Product Recognition System
Computer vision pipeline for detecting and recognizing retail products — detection, embedding, and similarity search over a product catalog.

`YOLO` `SigLIP2` `Vector Search` `Python`

### 🧠 Schema-Driven Data Transformation
An LLM pipeline that maps arbitrary, never-seen-before client files into a fixed destination schema — **without hardcoded column mapping rules**. Every output cell is graded by confidence (Green / Yellow / Red) and cited back to its source, so reviewers know exactly what to check.

Validated with blind evaluation and multi-run consistency analysis (~97% value agreement, ~92% grade agreement across runs).

`Anthropic SDK` `Pydantic` `Python` `Structured Outputs` `Evaluation`

### ⚙️ End-to-End RPA for Invoice Operations
Production automation covering email attachment intake → SharePoint/OneDrive file management → web portal data entry → ERP posting → logging and exception alerts.

The interesting parts were the edge cases: automating Kendo UI grids through their own data-source layer, driving PrimeNG components that fight synthetic events, surviving RDP session isolation, and designing Thai-language notification emails and Teams Adaptive Cards that read as *system states* rather than scary errors.

`Power Automate Desktop` `JavaScript` `PnP.PowerShell` `SAP B1` `Adaptive Cards`

**Also built** — a multimodal pipeline that turns screen recordings into As-Is swimlane diagrams and SOPs · an internal master-data web app (`React` · `Node.js` · `Prisma`) that lets ops self-serve the config feeding the RPA layer.

## 💡 How I work

- **Ship the boring 80% first.** A workflow that runs unattended beats a model that demos well.
- **Design for the person reading the output.** Confidence grades, source citations, and clear error messages matter more than raw accuracy.
- **Measure before believing.** Blind evals and consistency runs, not one lucky output.
- 🇹🇭 Building bilingual (TH/EN) tools for real teams.
